# Antigravity Agent Custom Rules - ZariYo

이 규칙은 자리요(ZariYo) 프로젝트 개발을 지원하는 에이전트(Antigravity)가 반드시 준수해야 하는 행동 지침 및 추가 규칙을 정의합니다.

---

## 1. 개발 및 문제 해결 활동의 의무 기록 (Automatic Logging Constraint)
- **개발 일지 자동 업데이트 (`work.md`)**:
  - 모든 설계 변경, 신규 컴포넌트 추가, 스타일 개편 등 새로운 활동이 종료될 때마다 프로젝트 루트의 `work.md` 파일 하단에 개발 내역과 작업 일시를 **누락 없이 실시간으로 자동 갱신**하여 보존해야 합니다.
- **트러블슈팅 이력 자동 업데이트 (`trouble.md`)**:
  - 개발 도중 마주한 컴파일 에러, 빌드 실패, 의존성 충돌, 툴 호출 예외 등의 오류가 발생하고 이를 해결할 때마다 프로젝트 루트의 `trouble.md` 파일에 에러 내용, 발생 원인, 극복 방법을 **자동으로 상세히 기록**해야 합니다.
- **작업 완료 워크스루 연동**:
  - 매 작업 단계 완료를 사용자에게 리포트할 때, `work.md`와 `trouble.md`가 함께 갱신되었음을 명확히 링크와 함께 리포트해야 합니다.
- **학습 내용 자동 업데이트 (`study.md`)**:
  - 사용자가 특정 기술의 원리, 코드의 역할, 인프라 동작 방식 등을 질문하고 이에 대해 답변을 제공한 경우, 해당 Q&A 내용을 날짜 및 시간과 함께 프로젝트 루트의 `study.md` 파일에 **자동으로 기록**해야 합니다.

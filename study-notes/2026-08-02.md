# [Study Note] 2026-08-02 Q&A 이력

## Q1. ZariYo 서비스에서 로그인이 창을 닫아도 계속 유지되는 원인이 무엇인가요?

### [질문 내용]
- 브라우저를 재시작하거나 페이지를 새로고침해도 사장님/유저의 로그인 상태가 자동으로 유지되는 원인에 대한 문의.

### [원인 및 동작 메커니즘]

1. **`localStorage` 기반 웹 스토리지 영속성 (Web Storage Persistence)**:
   - [LoginPage.tsx](file:///home/jaehyeon/바탕화면/portfolio/ZariYo/ZariYo-FrontEnd/src/pages/auth/LoginPage.tsx#L54), [KakaoCallbackPage.tsx](file:///home/jaehyeon/바탕화면/portfolio/ZariYo/ZariYo-FrontEnd/src/pages/auth/KakaoCallbackPage.tsx#L28)에서 로그인 성공 시 발급받은 JWT 인증 토큰과 유저 정보를 `sessionStorage`가 아닌 `localStorage`에 저장합니다.
   - `sessionStorage`는 탭이나 브라우저를 닫으면 토큰이 즉시 삭제되지만, `localStorage`는 브라우저를 종료하거나 컴퓨터를 재부팅해도 **사용자가 명시적으로 [로그아웃] 버튼을 클릭하거나 브라우저 쿠키/스토리지 데이터를 삭제하지 않는 이상 토큰이 영구히 보존**됩니다.

2. **자동 토큰 재발급 메커니즘 (Silent Refresh Token Flow)**:
   - [client.ts](file:///home/jaehyeon/바탕화면/portfolio/ZariYo/ZariYo-FrontEnd/src/api/client.ts#L40)의 Axios/Fetch 응답 인터셉터에서 짧은 수명의 Access Token(`zariyo_token`)이 만료(401 Unauthorized)되면 `localStorage`에 보존된 `zariyo_refresh_token`을 백엔드로 전달하여 **사용자 개입 없이 백그라운드에서 새 Access Token을 자동으로 재발급**받습니다.

3. **로그인 유지를 해제하거나 브라우저 종료 시 로그아웃되게 하려면?**:
   - `localStorage.setItem`을 `sessionStorage.setItem`으로 변경하거나, 로그인 시 "로그인 상태 유지 (Remember Me)" 체크박스 옵션을 제공하여 체크 시에만 `localStorage`를 사용하도록 분기하면 됩니다.

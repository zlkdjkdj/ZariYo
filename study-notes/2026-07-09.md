## 2. 공부해야 할 핵심 개념 & 로직

### 💡 React Context API를 활용한 테마(Theme) 전역 제공
어플리케이션 전역에서 화면 색상 모드(라이트/다크)를 실시간 반영하기 위해 Context를 선언합니다.

```typescript
const ThemeContext = createContext<ThemeContextType | undefined>(undefined);
```
* **동작 방식**: 최상단 컴포넌트인 `App.tsx`를 `<ThemeProvider>`로 래핑하면, 하위 수십 개의 컴포넌트들에게 명시적으로 테마 속성(Props)을 하나하나 전달(Prop Drilling)하지 않아도, 어떤 깊이에 있는 자식 컴포넌트든 관계없이 `useTheme()` 훅을 호출하여 다크/라이트 상태 및 전환 함수를 즉시 가져다 쓸 수 있습니다.

### 💡 브라우저 `storage` 이벤트를 이용한 크로스 탭(Cross-tab) 실시간 데이터 동기화
자리요 시스템에서는 고객 탭에서 좌석을 예약(임시 선점)하면, 사장님 탭 대시보드에서도 **새로고침 없이 실시간으로 좌석이 노란색(임시선점중)으로 변경**되어야 합니다.
이를 웹소켓 연동 전 프론트엔드 레벨에서 모사하기 위해 브라우저의 `storage` 이벤트를 활용합니다.

```typescript
// 다른 탭에서 localStorage의 값이 변경되었을 때 실행되는 이벤트 리스너
useEffect(() => {
  const handleStorageSync = (e: StorageEvent) => {
    if (e.key === 'zariyo_placed_elements' || e.key === 'zariyo_temp_occupied') {
      // 탭 데이터를 강제 동기화
      loadLatestData();
    }
  };
  window.addEventListener('storage', handleStorageSync);
  return () => window.removeEventListener('storage', handleStorageSync);
}, []);
```
* **핵심 원리**: `localStorage.setItem`을 통해 동일한 도메인의 로컬 스토리지를 업데이트하면, 브라우저는 해당 스토리지를 보고 있는 **다른 모든 탭/창에 `storage` 이벤트를 브로드캐스팅**합니다. 이 이벤트를 감지하여 화면 상태를 재렌더링함으로써 다중 탭 간의 완벽한 실시간 데이터 동기화를 이뤄냅니다.

## 3. 핵심 트러블슈팅
* **CSS @import 순서 경고**: Tailwind CSS v4 스타일 컴파일러 구동 시 외부 폰트 파일 임포트 구문이 하단에 가 있으면 CSS 문법 표준 위반 경고가 뜹니다. 폰트 임포트를 `@import "tailwindcss"` 보다 위에 오도록 최상단으로 옮겨 해결했습니다.
* **로그인 역할별 리다이렉트 버그**: 손님 계정으로 로그인했음에도 사장님 콘솔로 연결되는 분기 로직 상의 목적지 경로 하드코딩 오작동을 발견하여, 올바른 랜딩 경로인 `/reserve`로 연결되도록 정합했습니다.
* **컴포넌트 리팩토링 중 문자열 미종결 문법 에러**: 코드를 합치는 과정에서 문자열이 잘려 파싱이 깨진 부분을 꼼꼼한 수동 검사를 통해 괄호 및 텍스트를 복원하여 빌드를 정상화시켰습니다.
